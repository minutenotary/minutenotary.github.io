Sealed documents

Check that a sealed document is genuine

Every document Minute Notary seals carries a code and a cryptographic seal. Check it online in seconds, or offline with open-source code.

Two ways to check

Online with the code, or offline with the file

Online

Look up the code printed on the document

The check confirms the Minute Notary seal, the trusted timestamp and the tamper-evident record. It never shows what the document says.

Where is the code? In the small grey line at the top of every page of the sealed PDF: “Verify: minutenotary.ca/verify · Code: …”. The QR code on the seal opens the same check.

Offline

Verify the file itself, without uploading it

Drop the sealed PDF and its proof file (.proof.json) into the open-source verifier. It runs entirely in your browser; nothing leaves your computer.

Open the offline verifier

No proof file? Ask Minute Notary for the evidence package of your document. It holds the PDF, the proof, the public key and the timestamp token.

What gets checked

Five checks, in plain words

The offline verifier runs all five and gives one verdict.

genuine every check passed altered the file or the proof was changed incomplete a file could not be read
  1. 01

    The file is unchanged hash

    The fingerprint (SHA-256) of the exact PDF you hold equals the one recorded when it was sealed. Change one byte and this fails.

  2. 02

    The seal belongs to that file signature

    An ECDSA P-256 signature over that fingerprint checks out with the public key in the proof.

  3. 03

    The key is the issuer's key key

    Compare the key fingerprint the verifier prints with the one Minute Notary gives you, or give the verifier a trust list.

  4. 04

    The time is independent timestamp

    An RFC 3161 timestamp from an outside authority proves when the seal was made, not just what the server clock said.

  5. 05

    The seal is on the record ledger

    The seal's entry in an append-only, hash-chained ledger recomputes from the proof, so it cannot be slipped in later.

For developers and courts

The verifier is open source

Library, command line and browser page under the MIT licence, with the seal format documented so anyone can write their own checker.

# build once from source (the npm package is not published yet)
$ git clone https://github.com/minutenotary/sealed-pdf-verify
$ cd sealed-pdf-verify && npm ci && npm run build:lib

# check a sealed PDF next to its proof file
$ node dist/cli.js document.pdf --proof document.proof.json

# or a whole evidence package
$ node dist/cli.js evidence.zip
